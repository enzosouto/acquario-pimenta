06

Operação de campo Bônus

Registro simples de eventos e presença das equipes regionais — evolução do projeto, entregue se o cronograma do primeiro ciclo permitir.

Meta, TSE, IBGE e o site entram no escopo inicial. Google Ads é conectado assim que o acesso da conta de anúncios for liberado pela campanha. Todo acesso é feito por API oficial, com tratamento de dados pessoais conforme a LGPD.
